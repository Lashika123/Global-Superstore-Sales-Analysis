
# Global Superstore Sales Analysis | Tableau

## 📌 Project Overview
This project focuses on analyzing global retail sales data using Tableau to understand business performance, sales trends, profitability, and geographical distribution.

An interactive Tableau workbook containing 8 worksheets was developed to explore key business metrics and generate meaningful business insights.

## 🎯 Project Objectives
- Analyze overall sales and profit performance.
- Identify top-performing countries and regions.
- Understand sales trends and seasonal patterns.
- Evaluate product and category performance.
- Explore future sales trends using forecasting.
- Identify patterns using clustering.
- Develop interactive visualizations for business analysis.

## 🛠️ Tools & Technologies
- Tableau Desktop
- Global Superstore Dataset
- Data Visualization

- Parameters
- Forecasting
- Clustering

## 📂 Dataset Description
The project uses three datasets:

1. **Orders:** Contains order details, customer information, product details, sales, profit, quantity, and geographical information.
2. **People:** Contains regional manager information.
3. **Returns:** Contains information about returned orders.

These datasets were connected in Tableau to support different aspects of business analysis.

## ⚙️ Project Implementation

### 1. Data Connection
Connected the Orders, People, and Returns datasets to Tableau and established the required data relationships.

### 2. Data Exploration
Explored sales, profit, customer, product, and geographical information to understand business performance.

### 3. Sales Trend Analysis
Analyzed sales performance over time to identify growth patterns and changes in business activity.

### 4. Seasonality Analysis
Explored recurring sales patterns across different time periods to understand seasonal variations.

### 5. Forecasting
Used Tableau's forecasting functionality to estimate potential future sales trends based on historical data.

### 6. Clustering
Applied Tableau clustering to group similar data points and explore patterns in the dataset.

### 7. Top 10 Countries Parameter
Created a dynamic Top 10 Countries parameter to explore and compare country-wise sales performance.

### 8. Geographical Map
Developed a map visualization to understand sales distribution across different countries.

### 9. URL Action
Implemented a URL action that allows users to click on a country and navigate to its corresponding Wikipedia page.
